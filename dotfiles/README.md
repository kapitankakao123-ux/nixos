# dotfiles — снимок конфигов deskjet

Снято с deskjet (Arch) 2026-09-11, перед установкой NixOS. Задумано как
**общая база для kitjet и deskjet**: клавиши, оболочка, терминал — одинаковые,
различаются только мониторы.

**Пока НЕ разворачивается home-manager'ом.** Это снимок в git. Раскладку на
две машины делаем после установки deskjet, когда обе на NixOS и схему можно
проверить вживую.

## Что внутри

| Каталог | Что |
|---|---|
| `niri/config.kdl` | основной конфиг niri, в конце — `include` фрагментов DMS |
| `niri/dms/binds.kdl` | **клавиши** |
| `niri/dms/outputs.kdl` | **мониторы — свои на каждой машине** |
| `niri/dms/*.kdl` | остальное, что генерирует DMS: цвета, раскладка, анимации, правила окон |
| `ghostty/` | конфиг и единственный используемый шейдер `cursor_frozen.glsl` |
| `DankMaterialShell/` | `settings.json`, настройки плагинов, список плагинов, CSS для Firefox/Zen |

## Что не взято и почему

- **Код плагинов DMS** (`plugins/`, `plugins/.repos/`) — чужие репозитории,
  восстанавливаются по `plugins.lock.json`.
- **Шейдеры ghostty**, кроме используемого, — это клон
  `https://github.com/hackr-sh/ghostty-shaders` со своей `.git`. Целиком он
  стал бы вложенным репозиторием, а нужен один файл.
- **Темы ghostty** — палитра Catppuccin Latte вписана прямо в `config`.
- Бэкапы редакторов: `*.bak*`, `*.backup*`.

## Секреты вычищены

В `DankMaterialShell/plugin_settings.json` были два токена, заменены на `""`:

- `homeAssistantMonitor.hassToken` — долгоживущий токен HA (старого, на
  `192.168.10.105`, которого больше нет);
- `musicLyrics.musixmatchToken` — ключ сервиса текстов песен.

После разворачивания их надо вписать заново через интерфейс DMS. **В git
не коммитить** — правило из `CLAUDE.md`.

## Что учесть при раскладке

- **DMS сам пишет `dms/*.kdl` и `settings.json`**, когда меняешь настройки в
  его интерфейсе. Обычный `home.file` сделает их ссылками в `/nix/store` только
  для чтения — и настройки DMS перестанут сохраняться. Нужен
  `mkOutOfStoreSymlink` на изменяемые файлы в репозитории. Но сперва проверить,
  как DMS записывает: если через «записать во временный + переименовать»,
  он заменит симлинк обычным файлом.
- В `config.kdl` есть привязки к этой машине помимо мониторов: рабочие
  столы с `open-on-output "DP-1"` и `spawn-at-startup "sunshine"`.
