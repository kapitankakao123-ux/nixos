# Бэкапы и репликация

Замена Proxmox Backup Server: **sanoid** делает снапшоты по расписанию, **syncoid** гоняет их инкрементально через `zfs send/recv`.

Направление: `kitjet` (источник) → `rpinix` (приёмник).

## Схема

| Где | Что | Роль |
|---|---|---|
| `kitjet` | sanoid, шаблон `data` | 24 часовых, 14 дневных, 6 месячных, автопрунинг |
| `kitjet` | syncoid, ежедневно | `tank/media` → `root@rpinix.lan:backup/media` |
| `rpinix` | sanoid, шаблон `backup` | снапшоты **не создаёт** (`autosnap = false`), только чистит старые |

Шаблон `backup` на приёмнике важен: если оставить `autosnap = true`, Pi начнёт делать свои снапшоты поверх приезжающих и репликация рассыплется.

## Настройка

- [ ] Пул `tank` на kitjet импортирован, датасеты созданы (`tank/media`, `tank/vm`)
- [ ] Пул `backup` на Pi создан — [[11-rpinix]]
- [ ] Сгенерировать ключ для syncoid: `sudo ssh-keygen -t ed25519 -f /var/lib/syncoid/id_ed25519 -N ""`
- [ ] Публичную часть положить в `authorized_keys` root на Pi
- [ ] Проверить заход руками: `sudo ssh -i /var/lib/syncoid/id_ed25519 root@rpinix.lan`
- [ ] Первый прогон вручную, он самый долгий: `sudo syncoid --recursive tank/media root@rpinix.lan:backup/media`
- [ ] Включить таймер и проверить: `systemctl list-timers | grep syncoid`
- [ ] Через сутки убедиться, что снапшоты доехали: `ssh rpinix zfs list -t snapshot backup/media`

## Проверка восстановления

Бэкап, который не проверяли, бэкапом не является.

- [ ] Откатить тестовый датасет из снапшота: `zfs rollback tank/test@...`
- [ ] Достать один файл из снапшота через `.zfs/snapshot/`
- [ ] Поднять данные обратно с Pi на kitjet: `syncoid root@rpinix.lan:backup/media tank/restore-test`

## Что НЕ покрыто

- **Внешний бэкап.** Сейчас обе копии дома. Пожар/кража/шифровальщик забирают всё разом. Кандидат — restic на удалённый S3 для критичного (не для медиатеки).
- **Секреты.** Ключ syncoid лежит открытым файлом в `/var/lib/syncoid/`. До перехода на `sops-nix` — так, но помнить.
- **Конфиги самих машин** бэкапить не надо: они в git. Но репозиторий должен иметь remote, иначе он тоже в единственном экземпляре.
